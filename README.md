# hse_tgbot

Данный бот предназначен для того, чтобы через него студенты могли подгружать новости (текст + фото-материалы + ссылки на внешние ресурсы). 

*Пайп-лайн:*
- Студент через бота вносит необходимые данные
- Материалы отправляются администраторам (фиксированный список)
- Администраторы одобряют материал или нет
- Если материал одобрен, он автоматически появляется в ресурсах программы (телеграм-канал)
